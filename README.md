# TechShop Microservices

Репозиторий содержит микросервисную архитектуру интернет-магазина техники на языке **Go**. Проект спроектирован с упором на слабую связанность компонентов (Decoupling) и асинхронное взаимодействие через брокер сообщений.

---

### Список сервисов:

* **`user-service`** — Сервис управления аккаунтами. Отвечает за регистрацию, аутентификацию, авторизацию пользователей и выдачу JWT-токенов (`access` и `refresh`). Выступает в роли **Kafka Producer**.
* **`notification-service`** — Сервис уведомлений. Слушает события из шины данных, отправляет транзакционные письма (приветствие, подтверждение заказа) на SMTP-сервер. Выступает в роли **Kafka Consumer**.

---

## 🛠️ Технологический стек

* **Язык разработки:** Go 1.27.1
* **Брокер сообщений:** Apache Kafka (с Zookeeper)
* **Роутинг и API:** Встроенный `http.NewServeMux` (Go 1.22+ стиль)
* **Документация:** Swagger / Openapi 2.0 (`swaggo/http-swagger`)
* **Оркестрация / Контейнеризация:** Docker, Docker Compose (Multi-stage сборка)
